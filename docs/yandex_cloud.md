# Запуск KvizY в Yandex Cloud — по шагам (с iPad)

Делаешь один раз, ~30–40 минут. Потом каждый пуш в `main` сам обновляет приложение.

В ссылках ниже `<FOLDER_ID>` — это ID твоего каталога (шаг 2). Подставь его в адрес. 🟡 Адреса страниц консоли я не мог открыть сам — если какая-то ссылка не откроется, зайди на https://console.yandex.cloud и найди сервис поиском сверху по названию.

---

## Шаг 1. Платёжный аккаунт

Без него YandexGPT не работает, даже с грантом 🟡.

1. Открой https://billing.yandex.cloud/accounts
2. «Создать аккаунт» → физическое лицо → привяжи карту.
3. Проверь, что аккаунт **ACTIVE** (или TRIAL_ACTIVE с грантом).

## Шаг 2. Каталог и его ID

1. Открой https://console.yandex.cloud/cloud — там уже есть каталог `default`. Можно взять его.
2. Нажми на каталог. ID каталога (начинается с `b1g…`) виден в адресной строке после `/folders/` и на странице каталога. **Скопируй его** — это `YC_FOLDER_ID`.

## Шаг 3. Сервисный аккаунт (один на всё)

1. Открой `https://console.yandex.cloud/folders/<FOLDER_ID>/iam/service-accounts`
2. «Создать сервисный аккаунт», имя `kvizy`.
3. Добавь роли (кнопка «Добавить роль»):
   - `ai.languageModels.user` — YandexGPT;
   - `container-registry.images.pusher` — загружать образ;
   - `container-registry.images.puller` — контейнеру скачивать образ;
   - `serverless-containers.editor` — выкатывать ревизии;
   - `serverless-containers.containerInvoker` — на всякий случай для вызова;
   - `iam.serviceAccounts.user` — назначать аккаунт контейнеру;
   - `ydb.editor` — база.
   🟡 Если при деплое будет ошибка «Permission denied» — пришли мне текст, скажу, какой роли не хватает.
4. Открой созданный аккаунт → скопируй его **ID** (начинается с `aje…`) — это `YC_SA_ID`.
5. Там же: «Создать новый ключ» → **«Создать авторизованный ключ»** → «Скачать файл с ключами». Файл `authorized_key.json` откроется в «Файлах». Открой его, выдели **весь** текст (от `{` до `}`) и скопируй — это `YC_SA_JSON_CREDENTIALS`.
6. **API-ключ для ИИ можно не делать:** приложение возьмёт доступ к YandexGPT от этого же сервисного аккаунта 🟡. Если «Проверить связь» в приложении скажет «ключ не подошёл» — сделай тут же «Создать API-ключ» (область `yc.ai.languageModels.execute`) и вставь его в Настройках приложения.

## Шаг 4. Container Registry (хранилище образов)

1. Открой `https://console.yandex.cloud/folders/<FOLDER_ID>/container-registry`
2. «Создать реестр», имя `kvizy`.
3. Скопируй **ID реестра** (начинается с `crp…`) — это `YC_REGISTRY_ID`.
4. 🟡 Чтобы старые образы не копились (хранение платное, копейки): в реестре → «Политики жизненного цикла» → удалять образы старше 7 дней, оставлять последние 3.

## Шаг 5. База YDB Serverless

1. Открой `https://console.yandex.cloud/folders/<FOLDER_ID>/ydb`
2. «Создать базу данных», имя `kvizy`, тип **Serverless**. Остальное не трогай.
3. Когда база создастся, на её странице есть «Эндпоинт» вида
   `grpcs://ydb.serverless.yandexcloud.net:2135/?database=/ru-central1/b1g…/etn…`
   Раздели на две части:
   - `YDB_ENDPOINT` = `grpcs://ydb.serverless.yandexcloud.net:2135`
   - `YDB_DATABASE` = `/ru-central1/b1g…/etn…` (всё после `database=`)

Таблицы приложение создаст само при первом запуске.

## Шаг 6. Секреты в GitHub

Открой https://github.com/8hwbn2nfvy-dotcom/KvizY/settings/secrets/actions → «New repository secret». Добавь по одному:

| Имя | Что вписать |
|---|---|
| `YC_SA_JSON_CREDENTIALS` | весь текст авторизованного ключа (шаг 3.5) |
| `YC_FOLDER_ID` | ID каталога (шаг 2) |
| `YC_SA_ID` | ID сервисного аккаунта (шаг 3.4) |
| `YC_REGISTRY_ID` | ID реестра (шаг 4) |
| `YDB_ENDPOINT` | из шага 5 |
| `YDB_DATABASE` | из шага 5 |
| `KVIZY_PASSWORD` | пароль для входа в приложение |
| `SESSION_SECRET` | длинная случайная строка |
| `KEY_SECRET` | ещё одна длинная случайная строка. **Не меняй потом** — иначе сохранённые ключи ИИ придётся вводить заново |

Для `KVIZY_PASSWORD`, `SESSION_SECRET`, `KEY_SECRET`: только латинские буквы и цифры, **без запятых и пробелов** (запятая ломает передачу переменных контейнеру). Длинную строку удобно сделать в «Пароли» на iPhone: «Новый пароль» → скопировать.

## Шаг 7. Первый запуск

1. Открой https://github.com/8hwbn2nfvy-dotcom/KvizY/actions/workflows/deploy.yml
2. «Run workflow» → «Run workflow». Подожди 3–5 минут, пока все шаги станут зелёными.
3. В шаге «Новая ревизия контейнера» в конце будет строка **«Адрес приложения:»** и ссылка вида `https://bba….containers.yandexcloud.net/`. Это твой постоянный адрес. (Его же видно в `https://console.yandex.cloud/folders/<FOLDER_ID>/serverless-containers` → `kvizy`.)

Если шаг красный — открой его, скопируй текст ошибки и пришли мне.

## Шаг 8. Проверка

1. Открой `<адрес>/api/health` — должно быть `"ok": true` и `"db_kind": "yql"`.
2. Открой `<адрес>` → введи пароль.
3. Настройки → ИИ → провайдер **«Пробный (без денег)»** → Сохранить. Создай маленький квиз из текста — проверишь, что всё работает, бесплатно.
4. Настройки → ИИ → **YandexGPT**, модель Lite, ID каталога (уже подставлен) → «Проверить связь». Должно быть «Работает ✓».
5. Создай настоящий квиз.

## Шаг 9. Иконка на экран «Домой»

**iPhone:**
1. Открой адрес приложения в **Safari**, войди.
2. Внизу кнопка «Поделиться» (квадрат со стрелкой вверх). На новых iOS она может быть в меню «…».
3. Пролистай → «На экран „Домой“» → «Добавить».
4. Открывай KvizY с иконки — без строки браузера.

**iPad:**
1. Safari → адрес приложения → войди.
2. Кнопка «Поделиться» — справа вверху, рядом с адресной строкой.
3. «На экран „Домой“» → «Добавить».

Пароль нужно ввести один раз в самом приложении с иконки (у него своя «память», отдельная от Safari).

## Сколько это стоит (прикидка 🟡 — цены и квоты проверь по ссылкам)

**Serverless Containers** (https://yandex.cloud/ru/docs/serverless-containers/pricing): бесплатно в месяц — 1 000 000 вызовов и ограниченный объём CPU и памяти 🟡.
Твой расход: один квиз ~ 60 запросов к серверу (карточки, статус) + ~1 минута работы при создании. Даже 100 квизов в месяц ≈ 10 000 вызовов и ~2–3 часа работы контейнера (1 ГБ, 1 ядро). Это **намного меньше** бесплатного объёма вызовов; по времени работы — должно влезть, но проверь цифры квоты на странице цен 🟡.

**YDB Serverless** (https://yandex.cloud/ru/docs/ydb/pricing/serverless): бесплатно 1 000 000 «единиц запросов» (RU) и 1 ГБ в месяц 🟡. Обычная работа — десятки тысяч RU в месяц. Больше всего RU тратит загрузка больших файлов (они временно лежат в базе кусками): файл 15 МБ ≈ 30–50 тысяч RU 🟡. Если превысишь — дальше копейки за миллион RU.

**YandexGPT** (https://yandex.cloud/ru/docs/foundation-models/pricing): Lite ≈ 0,20 ₽, Pro ≈ 1,20 ₽ за 1000 токенов 🟡; 10 бесплатных запросов в час 🟡.
Один квиз на 10 вопросов по лекции ~ 8 000 токенов текста + ~4 000 токенов ответа ≈ 12 000 токенов: **≈ 2,4 ₽ на Lite, ≈ 14 ₽ на Pro**. Проверка открытого ответа ~ 500 токенов (≈ 0,1 / 0,6 ₽), замена вопроса ~ 1–2 ₽ на Pro.
500 ₽ в месяц ≈ 200 квизов на Lite или ~35 на Pro. Расходы видны внизу Настроек.

**Container Registry:** хранение образов — копейки в месяц, если включить политику удаления старых (шаг 4.4) 🟡.

## Как сократить «просыпание» (бесплатно)

Уже сделано: лёгкий образ, ленивые импорты, оболочка из кэша. Контейнер засыпает после простоя; первый запрос после сна ждёт запуска 🟡 (ожидаю 2–6 секунд, измерь сам: открой `/api/health` после часа простоя — в ответе `uptime_sec` маленький, значит контейнер только что проснулся).
Если будет мешать: можно держать 1 «подготовленный экземпляр» — это уже платно 🟡, поэтому не включал.
